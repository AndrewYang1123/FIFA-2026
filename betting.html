賠率約 1.8x – 2.1x

小球（2球或以下）= 1.90x

📐 凱利公式 — 科學計算投注金額

凱利公式幫助計算最優投注比例，在期望值為正時最大化長期回報：

f* = (bp - q) / b

其中：
f* = 建議投注比例（佔總預算）
b = 淨賠率（如賠率2.0，則b=1）
p = 你估計的獲勝機率（如50%=0.5）
q = 輸的機率（1-p）

實例：阿根廷冠軍，賠率3.5x（b=2.5），你估計獲勝機率30%（p=0.3，q=0.7）
f* = (2.5×0.3 - 0.7) / 2.5 = (0.75-0.7)/2.5 = 0.02 = 2%
若你的預算是$500，建議投注：$10

實踐上建議使用「半凱利」（f*/2），降低波動性

💎 專業投注小技巧

📊 比較賠率

同一場賽事，PlayNow、BetMGM、Bet365的賠率可能差10-15%。投注前務必比較，選最高賠率。差1.9x vs 2.1x，長期影響巨大。

🎁 善用迎新優惠

BetMGM、FanDuel等提供首次存款匹配優惠（如存$100送$100）。世界盃期間通常有特別促銷。注意「流水要求」條款。

⏰ 早鳥投注冠軍

世界盃冠軍的賠率在開賽後會隨著球隊表現快速變動。早早鎖定熱門隊的高賠率，比等到淘汰賽後更划算。

📉 避免「追數」

輸了之後加大投注金額想補回損失，是最常見的錯誤。每注按計劃金額投注，輸了就是娛樂成本，不要「報仇」。

🔄 現金兌換功能

Bet365等平台提供「提前結算」(Cash Out)。如果你的投注正在贏，可以提前兌現，不必等比賽結束。適合實時投注。

🚫 設定存款限額

PlayNow等平台允許設定每日/每週存款上限。建議所有用戶都設置這個功能，強迫自己控制預算，防止過度投注。
